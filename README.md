# Web Interface for Algorithm Examples

This repository now includes a web interface to demonstrate various sorting and searching algorithms.

## How to Use

1.  Clone this repository or download the files.
2.  Open the `index.html` file in your web browser.
3.  You will see a list of algorithm examples (e.g., Bubble Sort, Binary Search).
4.  Click on any example link.
5.  The input data used for the algorithm and the result (e.g., sorted array, index found) will be displayed below the links.

This interface allows you to see the algorithms in action with predefined datasets.
